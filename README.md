# Lidové kroje

Modern public website for **Lidové Tradice a Řemesla** in Uherský Ostroh. It recreates [lidove-kroje.cz](http://www.lidove-kroje.cz) as a Nuxt site: costume sewing, rental, repairs, weaving, embroidery, courses, gallery, and contact.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Nuxt
- Vue 3 Composition API
- Tailwind CSS
- Static content in `app/data/content.ts`

Photos come from the original workshop site. The e-shop stays at [siti-kroju.cz](https://www.siti-kroju.cz/).
